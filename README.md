# GPA Calculator (C++)

A simple console-based GPA calculator written in C++.

This program calculates GPA based on course credits and grading rules. It processes academic performance data, applies grade conversion logic, and computes the final GPA automatically.

## Features

* Credit-weighted GPA calculation
* Grade conversion based on academic rules
* Failed course handling
* Console-based user input

## Technologies

* C++
* STL (Standard Template Library)

## Purpose

This project was created to automate GPA calculation and practice problem-solving, algorithmic thinking, and C++ programming.
